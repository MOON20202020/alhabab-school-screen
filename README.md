# شاشة مدرسة الحباب بن المنذر للتعليم الأساسي

شاشة عرض لتلفاز المدرسة، مع لوحة تحكم من الجوال.

## الروابط

- **الشاشة (تُفتح على التلفاز):** https://moon20202020.github.io/alhabab-school-screen/
- **لوحة التحكم (من الجوال):** نفس الرابط وفي آخره `#admin`، أو امسح الباركود الظاهر على الشاشة.

## ما تعرضه الشاشة

- الساعة والتاريخ الميلادي والهجري
- الحصة الحالية والدقائق الباقية والحصة التالية
- الإعلانات (تتبدل تلقائيًا، مع صورة اختيارية)
- طالب الأسبوع
- الفعاليات القادمة مع عدّ الأيام
- جدول اليوم
- شريط الأخبار
- عرض صور وفيديو بملء الشاشة (يوتيوب، Google Drive، روابط مباشرة)

## الإعداد (مرة واحدة)

الشاشة تحتاج مشروع Firebase حتى تعمل لوحة التحكم:

1. أنشئ مشروعًا في https://console.firebase.google.com
2. Authentication ← فعّل Email/Password ← أضف مستخدمًا: `admin@alhabab.screen` بكلمة سر تختارها
3. Realtime Database ← أنشئ قاعدة بيانات، ثم الصق هذه القواعد في Rules:
   ```json
   { "rules": { "screen": { ".read": true, ".write": "auth != null" } } }
   ```
4. Project settings ← Your apps ← تطبيق ويب، وانسخ إعداداته
5. في ملف `index.html` ضع الإعدادات مكان `var FIREBASE_CONFIG = null;`

بعدها سجّل الدخول في لوحة التحكم باسم المستخدم `admin` وكلمة السر.
